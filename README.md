# تحويل py إلى exe عبر GitHub

## الإعداد (مرة واحدة)
1. أنشئ حسابًا مجانيًا على github.com.
2. أنشئ مستودعًا جديدًا (New repository) واجعله Private.
3. ارفع محتويات هذا المجلد كما هي، مع مجلد `.github` (استخدم Add file ← Upload files).

## التحويل
1. ضع سكربتك باسم `script.py` (استبدل الموجود) وارفعه. سيبدأ البناء تلقائيًا.
2. أو افتح تبويب Actions ← Build EXE ← Run workflow لتغيّر الاسم والخيارات والمكتبات.
3. انتظر دقيقة تقريبًا حتى تظهر علامة ✓ خضراء.
4. افتح التشغيل المكتمل، ومن أسفل الصفحة (Artifacts) حمّل الملف المضغوط وفيه الـ exe.

## ملاحظات
- إن احتاج سكربتك مكتبات، ضع أسماءها في ملف `requirements.txt` أو في خانة packages.
- الملفات المحمّلة من Artifacts تُحذف بعد 90 يومًا.
